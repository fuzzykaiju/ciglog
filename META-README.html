widgets Features

  • Daily log - cravings, cigarettes smoked, money spent, and minutes of life lost, per day
  • Precise or quick logging - exact time entry, or one-tap "just now / 5m ago / 1hr ago" presets
  • Craving intensity - low circle, mid circle, high circle for every craving
  • Smart Logging - long-press a smoke to log the craving and cigarette together in one step
  • Smart Craving Inference - for smokes logged the regular way, links to a craving from shortly before, or estimates one if none was logged, within a configurable time window
  • Optional Daily Limit - set a target; changes are tracked by date, so past analytics always reflect the limit that was active at the time
  • Triggers - 30+ presets across 4 categories, plus up to 3 custom triggers, with one-tap copy from a recent craving
  • Timeline view - every event of a day in order, with gaps between them and trigger detail on tap
  • Full edit mode - modify or delete any entry, any day
  • Analytics hub - weekly review, monthly calendar, trigger rankings, behavioural insights, and time-of-day patterns
  • CSV export / import - full backup, or move your data elsewhere
  • Auto-detected skipped days - mark them clean, or fill them in later
  • Installable - works offline, add to home screen

person_play How to Use

  • Tap sentiment_frustrated to log a craving
  • Tap smoking_rooms to log a cigarette - long-press to log both at once
  • Tap keyboard_arrow_down for a day's timeline and notes
  • Tap more_vert to edit or delete entries
  • Tap warning on a skipped day for more options
  • Open the side menu for Charts, Analytics, Settings, and data export/import

code_blocks Tech Stack

  • Plain HTML, CSS, Vanilla JS — no frameworks
  • Chart.js for charts, Material Symbols for icons
  • Browser localStorage for data - no account, no cloud
  • Service Worker + Web App Manifest for offline use and installability

database Data Model

  • Entries keyed by date (dd-mm-yyyy), each with cravings, smoked cigarettes, notes, and skipped/clean flags
  • Cravings carry time, intensity, triggers, and a source tag (manual, smart, or inferred)
  • Inferred cravings are estimates, not logged data - excluded from CSV export and hidden from Edit and Timeline views
  • Triggers: 4 categories, multiple selectable per entry, up to 3 custom triggers
  • CSV export/import for backup and migration

analytics Analytics

  • Week in Review: 7-day stats vs. the previous week - smoked, cravings, resistance rate, clean days/streak, money, time, and top triggers. Shows confirmed vs. estimated figures when Craving Inference is on.
  • Monthly Calendar: smoking days highlighted, browse any month
  • Period Overview: totals for any window from a week to two years
  • Insights: a rotating, priority-ranked set of behavioural patterns - peak smoking time, strongest trigger, spending projection, smoking trend, and personal streaks/records
  • Trigger Rankings & Combinations: which triggers (and trigger pairs) most often lead to smoking, once enough data exists
  • Time of Day: when cravings and smoking cluster across the day
