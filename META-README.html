widgets Features

  • Daily log — cravings, cigarettes smoked, money spent, and time lost, per day
  • Quick logging — exact time entry, or one-tap presets ("just now", "5m ago"...)
  • Craving intensity — low circle, mid circle, high circle
  • Smart Logging — long-press a smoke to log the craving and cigarette together
  • Craving Inference — auto-links or estimates a craving when a smoke is logged without one, within a configurable window
  • Optional Daily Limit — set a target; changes are tracked by date for accurate history
  • Triggers — 30+ presets across 4 categories, plus up to 3 custom triggers
  • At a Glance — visual trend cards: smoking pattern, resistance rate, intensity mix, limit adherence, time of day
  • Analytics — weekly review, monthly calendar, trigger rankings, behavioural insights
  • Full edit mode, CSV export/import, auto-detected skipped days, installable offline PWA

person_play How to Use

  • Tap sentiment_frustrated to log a craving
  • Tap smoking_rooms to log a cigarette — long-press to log both at once
  • Tap keyboard_arrow_down for a day's timeline and notes
  • Tap more_vert to edit or delete entries
  • Tap warning on a skipped day for more options
  • Open the side menu for At a Glance, Analytics, Settings, and data export/import

code_blocks Tech Stack

  • Plain HTML, CSS, Vanilla JS — no frameworks
  • Chart.js for charts, Material Symbols for icons
  • Browser localStorage for data — no account, no cloud
