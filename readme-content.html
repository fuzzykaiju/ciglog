CigLog - Cigarette Logger

A data-driven PWA to help you log cigarettes craved and smoked, and get analytics for money spent and minutes of life lost.

check_circle Features

  • Daily log - cravings count, cigarettes smoked, money spent, minutes of life lost
  • Precise tracking - log each event with exact time
  • Craving intensity - low circle, mid circle, high circle for every craving
  • Smart time presets - "just now", "5m ago", "1hr ago"
  • Timeline view - all events of a day in chronological order
  • Notes - add personal notes to each day
  • Full edit mode - modify or delete any entry
  • Interactive charts - smoked, cravings, intensity, and life lost
  • CSV export / import - backup or analyse your data elsewhere
  • Auto-detected skipped days - with option to mark as clean
  • Installable - works offline, add to home screen

build_circle How to Use

  • Tap sentiment_frustrated to log a craving with time & intensity
  • Tap smoking_rooms to log a cigarette with time
  • Tap keyboard_arrow_down to see the day's timeline and add notes
  • Tap more_vert to edit or delete entries
  • Tap warning on skipped days for more actions
  • Open the side menu for charts, export/import, and settings

code_blocks Tech Stack

  • Plain HTML, CSS, Vanilla JS — no frameworks
  • Chart.js for charts, Material Symbols for icons
  • Browser localStorage for data
  • Service Worker + Web App Manifest for offline & installability

database Data Model

  • Entries keyed by date (dd-mm-yyyy)
  • Each entry: cravings (time, intensity, triggers), smoked (time, count, price, triggers), notes, skipped/clean flags
  • Triggers: 4 categories (physiological, psychological, social, situational), multiple selectable per entry, up to 3 custom triggers
  • CSV export/import (backup/migration)

mobile_arrow_down PWA Features

  • Installable - works offline, add to home screen
  • Service Worker - enables offline functionality
  • Web App Manifest - defines app appearance and behavior
